# 《亂世》遊戲設計文件 v1.0

**三國鼎立 ｜ 四時輪轉 ｜ 一張百萬格的地圖，三個席位，一部會呼吸的史書**

---

## 30 秒版（先講這頁就夠）

> 一張 **1024 × 1024 格**的大陸地圖，三個國家（魏、蜀、吳），**一回合 = 一季**。
> 每個人自己的國家用**點擊**治理（徵稅、開墾、募兵、修城、調兵）；
> **打字只用來跟別人說話**——談判、締約、欺騙、求援。
> 每個國家對每個國家都有**信任值**，你簽過的每一張約、背過的每一次盟，全部記在案。
> 你看到的不是真相，是**你派斥候與間諜看到的世界**。
> 三條勝利路線：**一統天下 / 稱霸諸侯 / 受天明命**。

---

## 0. 六條設計原則

1. **點擊優先，文字為王** — 自己國內的一切操作都是點擊完成；文字只用來「對別人說話」。
2. **話不改變世界，承諾才改變世界** — 你愛怎麼講就怎麼講（真話、假話、廢話都行），但只有雙方「接受的條款」才會改動遊戲狀態。文字負責說服，條款負責生效。
3. **承諾有價，背信有罰** — 每一國對每一國都有信任值；每一張簽過的約都在案，撕約全世界都看得見。
4. **迷霧是核心** — 你看到的不是地圖，是你**以為**的地圖。
5. **四季為心跳** — 一回合 = 一季，四回合 = 一年。內政、行軍、外交共用同一個節拍。
6. **一切可回放** — 每一步都有史官紀錄，整局可以像棋譜一樣重播。

## 2. 回合結構（一季 = 一回合）

```
①  朝報 ── 天時、災異、敵情、上季結算（你看到的世界）
②  朝議 ── 公開外交：遣使、宣言、締約、索貢（所有人看得到）
③  密奏 ── 密信、暗盟、間諜密令（只有收信人看得到）
④  下令 ── 各國同時下令：內政、行軍、攻略（互相看不到！）
⑤  結算 ── 全體揭示、依序執行、戰鬥、生產、天災
⑥  史官 ── 結果記錄、史書更新 ── 進入下一季
```

### 各階段細節

| 階段 | 玩家做什麼 | 耗費號令點 |
|---|---|---|
| ① 朝報 | 閱讀奏摺堆：豐收、蝗災、敵軍集結、間諜回報 | 0 |
| ② 朝議 | 對所有人說話、提案、公開宣戰 | **0（說話永遠免費）** |
| ③ 密奏 | 密信、暗盟、派間諜 | 0（說話免費，行動要點） |
| ④ 下令 | 提交本季所有動作，**同時**結算 | 見第 11 章 |
| ⑤ 結算 | 觀看或等待，不能中途改令 | 0 |
| ⑥ 史官 | 看結果與日誌，規劃下一季 | 0 |

### 號令點（Command Points）

每國每季有 **5 點號令點**，這是「你能同時推進多少件事」的上限。

- 說話、提案、回覆 **永遠 0 點** —— 因為動嘴不用錢（但動兵要）。
- 一季最多 5 個實質動作，你必須學會取捨：**這季是募兵還是開墾？是攻城還是修城？**

|---|---|---|---|

| **糧** | 國家 | 農田、屯田、秋收 | 養兵（最大開銷）、賑災、圍城 |
| **人口** | 城池 | 自然增長 | 稅基、兵源；戰亂與瘟疫會掉 |
| **民心** | 城池 | 安撫、豐收、勝仗 | 過低 → 民變、徵兵打折 |
| **治安** | 城池 | 守軍、吏治、巡查 | 防諜、稅收效率、防地方叛亂 |
| **士氣** | 軍隊 | 訓練、將領、勝仗、糧足 | 直接乘進戰力 |
| **威望** | 國家 | 守約、勝仗、義舉、歸還城池 | 外交籌碼、招降成功率 |
| **研究點** | 國家 | 學堂、人口 | 提升四條研究線 |

### 養兵的真實壓力

> 每 **1,000 兵每季耗糧 300**。
> 開局 45,000 兵 = **每季 13,500 糧**。一座普通農業城每季約產 900 糧。
> 18 座城 ≈ 16,200 糧／季 → 盈餘只有 2,700。
> **多養一萬兵，你就必須多打下一座城，否則秋收前就斷糧。**

這條數字是整個遊戲的引擎：它逼你擴張、逼你搶糧區、逼你季末必須做選擇。

### 季節對糧食的影響

| 季節 | 糧產 | 行軍 | 特色 |
|---|---|---|---|
| 春 | ×0.7 | 正常 | 開墾、募兵最佳 |
| 夏 | ×1.0 | 正常 | 適合出征 |
| 秋 | **×2.0** | 正常 | **大收——出征黃金期** |
| 冬 | ×0.3 | ×0.7（慢） | 消耗戰、民變與逃亡高發 |

## 4. 城池

### 4.1 一座城的資料

| 欄位 | 說明 |
|---|---|
| 名稱 / 座標 / 歸屬 | 誰的城 |
| 人口 | 10,000 – 500,000；稅收與兵源的根 |
| 民心 | 0–100；低於 25 有民變風險 |
| 治安 | 0–100；越高越能抓間諜 |
| 城防 | 0–5 級；影響守城戰力與圍城時間 |
| 駐軍 | 留守兵力（與野戰軍分開） |
| 建築 | 3–6 格：市集 / 農田 / 兵營 / 學堂 / 諜樓 / 糧倉 / 醫館 |
| 產出 | 金、糧（受地形 × 天時 × 民心 × 建築影響） |

### 4.2 建築效果

| 建築 | 花費 | 效果 |
|---|---|---|
| 市集 | 800 金 | 金 +30% |
| 農田 | 700 金 | 糧 +30% |
| 兵營 | 1,000 金 | 募兵成本 −20%，練兵 +1 |
| 學堂 | 1,200 金 | 研究點 +3／季 |
| 諜樓 | 1,200 金 | 治安 +10，可容納間諜 |
| 糧倉 | 900 金 | 糧上限 +50%（防荒） |
| 醫館 | 900 金 | 瘟疫死亡率減半，人口增長 +20% |

### 4.3 攻城與佔領

- **圍城**：把城圍住，每季結算。城內糧耗盡 → 守軍投降或強行突圍。
- **強攻**：兵力需 **3 : 1** 以上，或有攻城器械；傷亡大但快。
- **佔領後**：民心歸零、治安歸零，需要數季安撫才會恢復產出。
- **屠城**（可選）：立刻平定但民心永久 −30、威望 −20。**做壞人很方便，但代價是往後十年沒人敢跟你結盟。**

## 6. 戰鬥

### 6.1 戰力公式

```
戰力 = 兵力
     × 兵種係數        （配合相剋 0.8 – 1.3）
     × (1 + 訓練 × 0.10)
     × (0.5 + 士氣 / 200)     ← 士氣 100 → ×1.0，士氣 0 → ×0.5
     × (1 + 統率 / 200)       ← 名將可讓戰力翻近一倍
     × 地形係數        （守方 +0 ~ +50%）
     × 補給係數        （補給 0 → ×0.6）
     × 天時係數        （冬 ×0.9，疫病 ×0.7）
```

### 6.2 戰鬥流程

1. **遭遇**：兩軍同格、或一方下達攻擊令。
2. **最多 5 輪**：每輪雙方各承受「敵方戰力 × 8%」的損失，士氣同步下跌。
3. **結果判定**：
   - 士氣先歸零者 **潰散**（額外損兵 30%，退往最近己方城池）。
   - 5 輪後未分勝負 → **守方留場**（守方勝）。
   - 一方殲滅 → 全軍覆沒。

### 6.3 伏擊／劫糧／斷補

- **設伏**：在森林／丘陵預先布置，敵軍進入該格時首輪傷害 ×1.5、敵方士氣 −20。
- **劫糧**：攻擊敵軍補給線，目標補給 −40，敵方戰力立即受挫。
- **斷補**：以騎兵繞後封鎖，敵軍每季逃兵 10%。

### 6.4 為何「戰報」比畫面重要

每一場戰鬥都會產生一份戰報：誰先動、誰先潰、損失多少、哪個將領做了什麼。**這份戰報就是玩家下季決策的依據**，也是本遊戲最核心的閱讀樂趣——你是在讀一份軍報，而不是看一段動畫。

## 7. 外交、信任與條約

### 7.1 三層外交

| 層 | 形式 | 會不會改狀態 |
|---|---|---|
| **說話** | 自由文字，公開或密信 | **不會**。純粹說服對方 |
| **提案** | 結構化條款：同盟、割地、出兵、朝貢 | 對方**接受**才生效 |
| **行動** | 出兵、贈禮、斷交、背盟 | 立即生效，並被記錄 |

> 這是整份設計的心臟：**你可以撒任何謊，但世界只認簽了字的條款；而對方會不會簽，取決於他信不信你的話。**

### 7.2 條約種類

| 條約 | 內容 |
|---|---|
| 互不侵犯 | 約定期限內不得攻擊對方 |
| 同盟 | 共同作戰、互相支援 |
| 共同防禦 | 一方被攻擊，另一方須出兵 |
| 停戰 | 立即停止所有敵對行動 |
| 朝貢 | 一方每季向另一方輸送金／糧 |
| 割地 | 移交指定城池 |
| 通商 | 雙方每季金收入互助 |
| 借道 | 允許對方軍隊通過領土 |
| 聯姻 | 信任 +20，背盟代價加倍 |
| 稱臣 | 成為附庸，名義上獨立、外交受限 |

### 7.3 信任值（−100 ~ +100）

**每一國對每一國都有獨立的信任值**（魏對蜀、魏對吳、蜀對吳……雙向分開記錄）。

| 行為 | 對方對你的信任 | 你的威望 |
|---|---|---|
| 贈禮（每 1,000 金） | +3 | +1 |
| 守約（條約期滿履行） | +15 | +5 |
| 共同作戰（同場戰鬥） | +10 | +3 |
| 出兵救援盟友 | +20 | +8 |
| 歸還城池 | +25 | +10 |
| 拒絕盟友求援 | −15 | −5 |
| 散播謠言被識破 | −20 | −8 |
| 撕毀停戰 | −30 | −10 |
| 偷襲（未宣戰） | −40 | −12 |
| **背盟（攻擊盟友）** | **−50** | **−15** |
| 屠城 | −35 | −20 |

**威望**是全世界對你的總體評價：威望高，招降容易、提案容易被接受；威望低，所有人都防著你。
威望每季向 50 緩慢回歸 1 點——**時間會沖淡惡名，但很慢。**

### 7.4 背盟的藝術

背盟是這遊戲最強的戰術，也是最貴的。設計上刻意讓它划算但致命：

- 你可以在盟友與敵人打得兩敗俱傷時，突然奪取他的後方城池。
- 你**立刻**得到領土，**永久**失去那個盟友的信任，並讓**第三國**對你的信任 −15（旁觀者也會怕）。
- 接下來的每一個提案，對方都會要求你「先給實質保證」（例如先割地、先送人質）——**騙過一次的人，很難再騙第二次。**

## 8. 諜報與迷霧

### 8.1 戰爭迷霧

你只能看見：

- 己方城池與其周邊 **3 格**
- 己方軍隊周邊 **2 格**
- 斥候／間諜所在的區域
- 其他格子：**一片模糊**

看到的敵軍也不是真相：遠處的敵軍只顯示「兵力等級」（少／中／多），實際數字要靠間諜或近距離斥候。

### 8.2 間諜任務

| 任務 | 花費 | 難度 | 效果 |
|---|---|---|---|
| 偵察 | 200 金 | 低 | 得知目標城兵力與糧草（準確度依諜報等級） |
| 竊取軍報 | 400 金 | 中 | 得知目標國一支部隊的動向 |
| 散播謠言 | 500 金 | 中 | 目標城民心 −10 |
| 偽造軍報 | 600 金 | 高 | **污染目標國的情報一季**（他看到的兵力是假的） |
| 挑撥離間 | 800 金 | 高 | 目標兩國之間的信任 −10 |
| 收買將領 | 1,000 金+ | 極高 | 目標將領忠誠下降，可招降 |
| 暗殺 | 1,500 金 | 極高 | 目標將領死亡（機率判定） |

### 8.3 抓間諜（你上一輪問的「level 能不能抓」）

每季結算時，每名間諜都會進行一次暴露判定：

```
暴露率 = 基礎 5%
       + 所在城治安 × 0.3%
       + 目標國諜報等級 × 4%
       + 該間諜累積嫌疑 × 0.2%
       − 掩護加成（商賈 −5% / 僧侶 −8% / 降將 −3%）
```

- 每次行動，該間諜 **嫌疑 +15**。
- 嫌疑 ≥ 80 → **必定暴露**。
- 暴露後，對方有兩個選擇：
  1. **公開處決** → 你威望 −8，對方威望 +5
  2. **秘密反用**（餵你假情報）→ 你完全不知道，繼續用他送來的假消息做決策

**第二種才是最狠的。** 而這一切，全部建立在你把「諜報」研究練到幾級。

### 8.4 反諜

- **巡查**：花 1 號令點，本季全境暴露率 +15%
- **清查**：花 300 金，單城嫌疑 −30
- **諜報等級**：每級使境內敵諜暴露率 +4%

每級花費：**20 / 40 / 70 / 110 / 160 研究點**。開局約 15 點／季。

## 12. 換手開關（親政 / 託孤 / 禪讓）

這是你們最想要的那個「隨時讓 AI 或人接手」的開關，用三國的話講：

| 模式 | 意思 | 誰在下令 |
|---|---|---|
| **親政** | 你自己來 | 人類玩家 |
| **託孤** | 丞相代政，你隨時可以拿回來 | AI 建議，人類按「准」 |
| **禪讓** | 全權交出去，你只看 | AI 全權 |

### 三種粒度的切換

1. **全局切換**：整國交給 AI 或收回。
2. **單項授權**：只有「軍事」交給 AI，內政與外交仍由你決定。
3. **單次請示**：這一季的這一件事，問 AI 怎麼做，你決定要不要用。

> **規則一致性**：不管誰在下令，走的都是同一份行動總表與同一道驗證。人類點擊、人類打字、AI 下旨——**在遊戲眼裡是同一種「命令」。**

**戲劇性來自這裡**：你可以把你最強的敵國設成「禪讓」，然後看它自己走向滅亡；也可以在決戰時刻把一國交給 AI，測試它能不能守住。


## 15. 一個回合的完整範例（請從這裡開始讀）

> **背景**：第 2 年秋季（第 7 回合）。魏最強，蜀吳之間有互不侵犯條約（簽於第 3 回合，尚餘 5 季）。
> 三國席位：魏 = AI，蜀 = 真人玩家，吳 = AI。

### ① 朝報（蜀玩家看到的）

```
【天時】北方豐收（冀州糧產 ×1.5）；荊州連雨，行軍消耗 +1
【災異】涼州流民南下，魏拒絕接收，魏威望 −3
【軍報】斥候報：魏軍有異動，許昌周邊兵力等級「多」
【密報】我方細作回報：魏之主力約 30,000 人，集結於許昌一帶（準確度 70%）
【國情】漢中糧足，襄陽城防 2 級，駐軍 8,000
```

### ② 朝議（公開）

- **蜀→吳**：「魏壓境，願續盟共抗。」
  附條款提案：`同盟（3 年）＋ 共同防禦 ＋ 荊州互不侵犯`
- **吳→蜀**：「可。但若魏先攻我，蜀須出兵三萬相助。」
  吳**修改條款**，加了一條 `出兵義務：三萬`
- **魏→全場**：「魏願與蜀通商，共利百姓。」 ← **這是一句謊話，用來掩護**

### ③ 密奏（私下）

- **魏→吳**（密信）：「蜀欲獨吞荊州，屆時必犯江東。不如你我分蜀，荊州歸你，益州歸我。」
  ← **離間計：目標是拆散蜀吳同盟**
- **魏**：派間諜入吳，掩護身分「商賈」，花 500 金
- **蜀**：下令清查（300 金），境內嫌疑 −30

### ④ 下令（三國同時提交，互相看不到）

| 國家 | 本季動作（號令點 5） |
|---|---|
| **魏** | ① 兵團 A（30,000）向東，目標襄陽（1 點）② 募兵 5,000（1 點）③ 修城（1 點）④ 密探入吳（1 點）⑤ 巡查（1 點） |
| **蜀** | ① 主力 24,000 進駐漢中（1 點）② 屯田（1 點）③ 贈吳 3,000 金（1 點）④ 清查（1 點）⑤ 開墾（1 點） |
| **吳** | ① 兵團向合肥集結（1 點）② 通商（1 點）③ 密探入魏（1 點）④ 修城（1 點）⑤ 練兵（1 點） |

### ⑤ 結算

```
【魏】兵團 A 違反互不侵犯條約，越境攻擊襄陽 —— 圍城開始
      魏→蜀 信任：72 → 22      （背盟 −50）
      魏 威望：61 → 46          （背盟 −15）
      蜀→魏 信任：65 → 15
      蜀→吳 信任：68 → 73       （贈禮 +3，共同防禦磋商 +2）
      吳→魏 信任：55 → 40       （旁觀背盟 −15：吳開始怕魏）
【荊州連雨】魏攻方效率 −20%，圍城進度僅 30%
【襄陽】守軍 8,000 擊退第一波攻勢，士氣 +10
【吳國密探】潛入許昌成功（魏治安 45 → 暴露率僅 6%）
【蜀國清查】於江陵抓獲魏諜一名 → 蜀選擇「秘密反用」，餵其假軍報
【天時】秋收：全國糧 +18,000
```

### ⑥ 史官紀錄（會永久寫入本局史書）

```
[第 7 回合 · 秋]
魏主背盟，興兵犯襄陽。時荊州大雨，魏軍困於城下。
蜀主遣使贈吳金三千，吳蜀盟好益固。
魏亦遣使說吳，欲共分蜀，吳未應。
魏諜入吳，蜀諜被捕而反用焉。
```

### 下一季的核心抉擇

> 吳國手握兩封信：**魏的「分蜀」密信**，和**蜀的三千金與盟約**。
> 魏的信任值 40（高風險高回報）；蜀的信任值 73（安全但收益有限）。
> **吳怎麼選，取決於操縱吳國的那顆腦袋。**

## 17. 為什麼這設計能撐起一篇論文（附註，先不必深究）

- 每個決策都被記錄成「**誰、看到什麼、做了什麼、結果如何**」，整局可重播。
- 迷霧可以是**可調的**：從只看斥候回報，到直接看穿全圖——這本身就是一個天然的比較變數。
- 「同一張地圖、同一個種子，換一顆腦袋（人／模型），戰爭就分岔」——這是最好拍、最好講、也最嚴謹的展示。
- 決策樹（41 個節點）是規則，自由文字是話術，兩者分工清楚，誰來玩都跑在同一套規則上。
